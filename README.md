# Goon Tracker Discord Bot

Бот собирает данные о последних появлениях "Гунов" (Goon Squad) в Escape from Tarkov
(режим PvE) с четырёх сайтов и выводит их по команде `!гуны`. Название карты — на
русском, время последнего появления — в МСК, плюс единообразное "X назад".

Источники:
1. https://www.tarkov-goon-tracker.com/pve
2. https://www.goon-tracker.com/pvetracker
3. https://tarkovbot.eu/goonstracker
4. https://eft.su/goons

## Установка

1. Установи Python 3.10+.
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```

## Создание Discord-приложения (если ещё нет)

1. Зайди на https://discord.com/developers/applications → New Application.
2. Вкладка **Bot** → Add Bot → скопируй **Token** (пригодится ниже).
3. В той же вкладке Bot включи **Message Content Intent** (без этого команда `!гуны`
   не будет читаться).
4. Вкладка **OAuth2 → URL Generator**:
   - Scopes: `bot`
   - Bot Permissions: `Send Messages`, `Embed Links`, `Read Message History`
   - Открой сгенерированную ссылку и добавь бота на свой сервер.

## Запуск

Linux / macOS:
```bash
export DISCORD_TOKEN="твой_токен"
python goon_bot.py
```

Windows PowerShell:
```powershell
$env:DISCORD_TOKEN="твой_токен"
python goon_bot.py
```

## Использование

В любом канале, куда добавлен бот:
```
!гуны
```

Бот выведет embed с последними локациями гунов по четырём источникам, карта — на
русском, время — в МСК плюс "X мин./ч./дн. назад". Есть кулдаун 15 сек. на сервер,
чтобы не спамить сайты-источники запросами.

## Откуда берётся время в МСК

- **tarkov-goon-tracker.com** помечает время в таблице суффиксом `z` (Zulu/UTC) —
  бот парсит это как UTC и добавляет +3 часа для МСК.
- **goon-tracker.com** подписывает время как `PST` — бот трактует это буквально
  как UTC-8 (как написано на самом сайте) и добавляет +11 часов для МСК.
- **tarkovbot.eu** вообще не указывает свою таймзону, зато сам показывает
  относительное "X hours ago" — бот использует именно это значение (текущий момент
  минус смещение), чтобы не гадать про таймзону сайта.
- **eft.su** тоже не указывает таймзону явно, но это русскоязычный сайт для
  русской аудитории — его время принимается как уже указанное в МСК напрямую,
  без конвертации.

Если какой-то из сайтов сменит формат/таймзону без предупреждения — соответствующий
парсер в `goon_bot.py` нужно будет поправить (см. ниже).

## Если парсинг перестал работать

Сайты периодически меняют вёрстку. Если бот пишет "⚠️ Не удалось распарсить данные":

1. Открой соответствующий сайт в браузере, нажми F12 → Elements.
2. Найди, как теперь оформлен блок с "последним появлением" (текст/таблица/классы).
3. В `goon_bot.py` подправь соответствующую функцию:
   - `parse_tarkov_goon_tracker()` — для tarkov-goon-tracker.com
   - `parse_goon_tracker()` — для goon-tracker.com
   - `parse_tarkovbot_eu()` — для tarkovbot.eu
   - `parse_eft_su()` — для eft.su

Все четыре функции принимают HTML-страницу и возвращают словарь с данными — их
можно менять независимо друг от друга, не трогая остальной код бота.
