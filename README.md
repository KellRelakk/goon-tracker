# Goon Tracker Discord Bot

Бот собирает данные о последних появлениях "Гунов" (Goon Squad) в Escape from Tarkov
с трёх сайтов и выводит их по команде `!goons`.

## Установка

1. Установи Python 3.10+.
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```

## Создание Discord-приложения (если ещё нет)

1. Зайди на https://discord.com/developers/applications → New Application.
2. Вкладка **Bot** → Add Bot → скопируй **Token** (пригодится ниже).
3. В той же вкладке Bot включи **Message Content Intent** (без этого команда `!goons`
   не будет читаться).
4. Вкладка **OAuth2 → URL Generator**:
   - Scopes: `bot`
   - Bot Permissions: `Send Messages`, `Embed Links`, `Read Message History`
   - Открой сгенерированную ссылку и добавь бота на свой сервер.

## Запуск

Linux / macOS:
```bash
export DISCORD_TOKEN="твой_токен"
python goon_bot.py
```

Windows (cmd):
```
set DISCORD_TOKEN=твой_токен
python goon_bot.py
```

## Использование

В любом канале, куда добавлен бот:
```
!гуны
```

Бот выведет embed с последними локациями гунов по всем трём источникам.
Есть кулдаун 15 сек. на сервер, чтобы не спамить сайты-источники запросами.

Команда `!гуны` содержит кириллицу — это нормально, discord.py прекрасно работает
с юникод-именами команд.

## Если парсинг перестал работать

Сайты периодически меняют вёрстку. Если бот пишет "⚠️ Не удалось распарсить данные":

1. Открой соответствующий сайт в браузере, нажми F12 → Elements.
2. Найди, как теперь оформлен блок с "последним появлением" (текст/таблица/классы).
3. В `goon_bot.py` подправь соответствующую функцию:
   - `parse_tarkov_goon_tracker()` — для tarkov-goon-tracker.com
   - `parse_goon_tracker()` — для goon-tracker.com
   - `parse_eft_su()` — для eft.su

Все три функции принимают HTML-строку и возвращают словарь с данными — их можно
менять независимо друг от друга, не трогая остальной код бота.
